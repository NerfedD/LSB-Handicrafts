Every screen here is the shared system, so it looks the same in either view — only the dashboard changes. The account block now lives top right on every screen, next to Alerts.

1Two dashboard views — a preference each person picks, not a decision made for them

Both are the same system — warm paper canvas, deep navy nav, cobalt actions, a clay accent for anything craft or production. Same data, same navigation, same rules. What differs is how much the dashboard assumes you already know, so each person chooses in My profile and their choice sticks. Standard is what a new account starts on; Large text is one tap away for anyone who wants it.

1bStandard view — the default. Opens with what needs doing, in sentences, each with one button; numbers demoted to a strip. Teaches the system to a first-time user without training.
